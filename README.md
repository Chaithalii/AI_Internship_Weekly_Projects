# AI_Internship_Weekly_Projects
A collection of AI internship projects demonstrating data analysis, machine learning, and NLP chatbot development using Python and popular AI libraries.
#  AI Internship Projects

This repository contains the projects completed during my Artificial Intelligence Internship. Each week's project focuses on a different AI concept, ranging from data analysis and machine learning to Natural Language Processing (NLP).

---

##  Projects Included

###  Week 1 – AI Data Analysis & Visualization

**Objective**

Analyze a real-world dataset using Python libraries such as Pandas and NumPy. Perform data cleaning, preprocessing, statistical analysis, and create visualizations.

**Technologies Used**

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

**Key Features**

- Dataset loading
- Data cleaning
- Data preprocessing
- Statistical analysis
- Charts and graphs
- Summary report

---

###  Week 2 – Machine Learning Prediction System

**Objective**

Develop a Machine Learning model using Scikit-learn to predict employee attrition.

**Technologies Used**

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib

**Key Features**

- Data preprocessing
- Label encoding
- Train-test split
- Random Forest Classifier
- Model evaluation
- Model saving
- Prediction system

---

###  Week 3 – Anime AI Chatbot

**Objective**

Develop a simple AI chatbot using Python and NLP libraries that answers predefined anime-related questions through intent matching.

**Technologies Used**

- Python
- NLTK
- Scikit-learn
- TF-IDF Vectorizer
- Cosine Similarity

**Key Features**

- Text preprocessing
- Intent matching
- Interactive chat interface
- Custom responses
- Error handling
- Anime recommendation chatbot
